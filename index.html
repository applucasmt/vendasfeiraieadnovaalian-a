📄 Relatório por Setor

💳 Configurar Maquininha

A Minizinha Chip 3 aceita Wi-Fi (LAN local) ou API Cloud (PagSeguro). Bluetooth foi substituído pelo Wi-Fi neste modelo — o sistema suporta os 3 modos.

📶 Wi-Fi Local

Digite o IP que aparece em Configurações → Rede da Minizinha. O navegador tentará acessar diretamente (só funciona se a maquininha expuser porta HTTP — geralmente não expõe; use como teste de rede).

☁️ PagSeguro Cloud (recomendado)

Integração oficial via API REST. Obtenha as credenciais em dev.pagbank.uol.com.br → Vendas → Aplicações → Criar aplicação → API de Pedidos (Orders).

🔵 Bluetooth (legado)

A Minizinha Chip 3 não suporta Bluetooth para integração. Este modo serve para outras maquininhas (ex: Moderninha Smart).
